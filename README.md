# 📦 Inventory System Manager

A simple and responsive inventory management application built with HTML, CSS, and Vanilla JavaScript.

The application allows users to add, edit, delete, search, and filter products while keeping track of inventory levels.

## 🚀 Features

- Add products
- Edit products
- Delete products
- Search products by name
- Filter products by category
- Track total products
- Track total items in stock
- Identify low-stock products
- Save inventory data using `localStorage`
- Responsive design for desktop, tablet, and mobile
- Currency formatting for product prices

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- LocalStorage
